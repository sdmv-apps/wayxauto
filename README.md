# WayXAuto

Android Auto on your motorcycle's display, over Wi-Fi. Download the APK from [Releases](https://github.com/sdmv-apps/wayxauto/releases/latest) or visit the website.

This repository holds only the download website and the signed APK releases. Each release includes a SHA-256 sidecar. WayXAuto is not affiliated with OMOWAY or Google. A project by SDMV.
